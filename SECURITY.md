# Security Policy

## Supported Versions

All versions are currently supported for security releases.

## Reporting a Vulnerability

The primary was we ask you to report issues is directly through [GitHub issues](https://github.com/TwoBrake/bun-monorepo/issues), however if the vulnerability requires confidentiality, you are able to contact us via email at [contact@inticate.com](mailto:contact@inticate.com).

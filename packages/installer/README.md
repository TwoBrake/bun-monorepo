    <h2>Getting Started</h2>
    <p>An opinionated starter template for TypeScript using the Bun ecosystem. The primary reason for this template being developed was to enhance the time it took for me to startup new projects without having to worry about restructuring the setup.</p>
    <p>Obviously the structure isn't ideal for every project, but for general TypeScript setups that require a multi-package/app monorepo structure, this may be what you've been looking for.</p>
    <p>A template/project can be created fairly easily due to our installation helper published on NPM. This is useable by running the following in your terminal.</p>
    <pre><code>npx @twobrake/create-monorepo</code></pre>
    <p>This will run the installation helper in your current directory and guide you through configuration steps to finalize the project. You will be asked to select a directory and it is important to prepare the directory <strong>before running the helper</strong>. Please ensure this directory is empty as an already populated directory could cause issues.</p>
    <p>If you prefer Bun over NPM's CLI due to it's performance enhancements, feel free to use the following command instead of the one above.</p>
    <pre><code>bunx @twobrake/create-monorepo</code></pre>
    <h2>Contributions</h2>
    <p>If you have a passionate interest in this project, feel free to make suggestions or direct contributions through <a href="https://github.com/TwoBrake/bun-monorepo/issues" target="_blank">GitHub issues</a>. You can also leave comments on other people's suggestions with more features you may want added. Please keep in mind, this project is not meant to be largely scaled as it is a starting point to <strong>your project</strong>.</p>
